# PokéVerse - Pokédex React

Proyecto académico desarrollado con React, Vite y PokéAPI. Incluye diseño responsivo, listado paginado de Pokémon y pantalla de detalles con estadísticas.

## Ejecutar localmente

```bash
npm install
npm run dev
```

## Publicar en GitHub Pages

1. Crear un repositorio en GitHub, por ejemplo `pokedex-react`.
2. Subir todos los archivos del proyecto.
3. Ejecutar `npm install` y luego `npm run build`.
4. En GitHub, ir a **Settings > Pages**.
5. Usar GitHub Actions o publicar el contenido de `dist`.

El proyecto utiliza `HashRouter`, por lo que las rutas funcionan correctamente en GitHub Pages.
